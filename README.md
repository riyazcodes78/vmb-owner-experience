# VMB — Owner Experience V2
Conceptual digital transformation prototype by Atelier North.

## Locked pitch
A digital command centre that connects villa owners with their properties, operations, guests and VMB in one continuous experience.

## Journey
OWNER HOME → PROPERTY → PERFORMANCE → OPERATIONS → REQUESTS → GUEST → COMMUNICATION → INTELLIGENCE → VMB ECOSYSTEM

All figures and interface states are illustrative concepts, not live VMB data.
